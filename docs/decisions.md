## 0001. 프리티어는 "항상 무료"만 반영한다

- 결정: "계산 조건"의 프리티어 빼기는 매달 무료인 사용량(데이터 전송 100GB, CloudFront 1TB·1,000만 건, Lambda 100만 건·40만 GB-초, DynamoDB 25GB)만 뺀다. 기본값은 꺼짐.
- 이유: 기간 한정 무료(12개월)와 신규 계정 크레딧은 정책이 자주 바뀌고 계정마다 달라서, 넣으면 초보자에게 틀린 금액을 보여줄 수 있다.
- 대신: 결과의 "계산 기준"에서 신규 계정이면 더 적게 나올 수 있다고 안내하고 AWS 프리티어 페이지로 연결한다.

## 0002. 아이콘은 Lucide + AWS 공식 아이콘, 브랜드 색은 네이비 + 오렌지

- 결정: 이모지를 쓰지 않는다. 일반 아이콘은 Lucide(`icon()`), AWS 서비스는 공식 아이콘(`glyph("aws:…")`). 색은 `css/styles.css`의 토큰만 쓴다.
- 이유: 이모지 위주 화면이 "AI가 만든 것 같다"는 피드백. 서비스 아이콘을 실제 AWS 콘솔과 같게 해서 초보자가 콘솔에서 다시 알아보게 한다.

## 0003. 방문 분석은 GoatCounter + Cloudflare Web Analytics (대체됨 → 0004)

- 결정: GoatCounter로 화면·이벤트를, Cloudflare로 방문 수·성능을 본다.

## 0004. 방문 분석은 GoatCounter만

- 결정: Cloudflare Web Analytics를 코드·설정·개인정보 안내에서 모두 뺐다. GoatCounter 코드는 `jylee`(Awscal 전용, which-ai는 `jylee2`).
- 이유: 보고 싶은 것(유입 경로, 인기 템플릿, 기능 사용)은 GoatCounter로 충분하다. 외부 스크립트와 개인정보 안내 항목을 하나 줄인다.
- 방식: 해시 화면마다 직접 세고(`no_onload`), 첫 화면만 `?utm_source=` 또는 referrer를 유입 경로로 보낸다. 쿠키 없음.

## 0005. 기본 조건 견적은 공유 랜딩 페이지 주소로 공유한다

- 결정: 값·이름·리전을 바꾸지 않은 견적은 `share/<템플릿>-<규모>.html`(배포 때 18개 생성)로 공유하고, 바꾼 견적은 `#/t/…` 링크로 공유한다.
- 이유: 카카오톡·슬랙 미리보기는 `#` 뒤를 읽지 못해 모든 링크가 같은 제목으로 보인다. 랜딩 페이지는 제목에 금액이 들어가서 받는 사람이 열어볼 이유가 생긴다.
- 지킬 것: 랜딩 페이지는 `noindex`, 템플릿 소개 페이지를 canonical로, 사이트맵에 넣지 않는다 (검색 결과에 같은 내용이 18개 생기지 않게).

## 0006. 시리즈 허브는 GitHub 프로필

- 결정: 다른 도구 모음(허브)은 GitHub 프로필 README로 하고, 푸터 "프로젝트"에 "만든 사람 · 다른 도구" 링크만 둔다. 헤더와 시리즈 배지는 쓰지 않는다. 결과 화면 맨 아래에 which-ai 개발자 버전 "백엔드·배포" 목록 링크(`?utm_source=awscal`)를 둔다.
- 이유: 만든 사람이 정한 방식(2026-11-18). 링크는 푸터에만 두어 초보자용 화면을 늘리지 않는다.

## 0007. 에이전트 지침은 AGENTS.md가 원본

- 결정: 규칙은 `AGENTS.md` 한 곳에 쓰고, `CLAUDE.md`는 `@AGENTS.md` 한 줄만 둔다. `.claude/settings.json`에서 main 푸시와 자동 생성 파일·워크플로·AWS 아이콘 수정은 묻게 하고, 커밋에 공동 작성 표기가 남지 않게 한다.
- 이유: 규칙이 대화에만 있으면 새 세션마다 사라진다. 두 파일에 복사하면 한쪽만 고쳐져 어긋난다.
